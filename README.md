# BiteSaver (Expo React Native + VS Code)

1. Open this folder in VS Code (`code .`).
2. `assets/images/icon.png` is pre-bundled in the ZIP export.
3. Install dependencies:
   ```bash
   npm install
   npx expo install
   ```
4. Start the Expo Metro server:
   ```bash
   npx expo start -c
   ```
5. Scan the QR code with **Expo Go** (iOS/Android) or press `a` for Android Emulator / `i` for iOS Simulator.
